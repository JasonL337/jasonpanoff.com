FTC Path Planner

A virtual simulation and path-creation application for our FTC robot, built in Unity, along with the path-following algorithm the robot runs.

Creating and modifying autonomous paths used to mean editing coordinates by hand. This app made it visual: draw a path, save it, push it to the robot, and watch it run. New paths took seconds instead of a session, and revising an old one stopped being something we avoided.

Demo

Or watch on YouTube.

In this video I draw a path, save it, push it to the robot’s memory, and run the self-contained path-following algorithm. The algorithm corrects the robot back onto the path even after it is nudged or pulled off course — as I do to it here.
