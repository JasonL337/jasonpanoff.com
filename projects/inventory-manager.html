Inventory Manager

A desktop stock tracker built with native Java UI over an AWS RDS database, written to learn database fundamentals from the ground up: schema design, queries, and reporting. It tracks quantities by category, flags items about to run out, and exports to CSV. The RDS instance has since been shut down, so this screenshot is what is left of it.
