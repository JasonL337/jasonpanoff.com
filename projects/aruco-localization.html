ArUco Robot Localization

A camera-based localization system in C++ that estimates robot position to within 4 cm on a 12×8 meter playing field.

How it works

Built in C++ with OpenCV’s ArUco detection, integrated into the robot software stack with ROS2. Webcam data was captured and replayed with ros2 bag so the pipeline could be tested without the robot, and the whole environment ran in Docker to keep deployment consistent across machines.
